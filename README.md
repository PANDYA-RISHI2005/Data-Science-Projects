# 📊 Projects

## 01. Student Performance Analyzer

**Category:** Data Analysis | EDA | Data Visualization

A Python-based project for analyzing student academic performance and identifying factors that influence student scores.

### Key Features

* Data loading and exploration
* Missing value analysis
* Duplicate value detection
* Statistical analysis
* Subject-wise performance analysis
* Top student identification
* Performance category analysis
* Study hours vs final score analysis
* Attendance vs final score analysis
* Correlation analysis
* Data visualization

### Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn


