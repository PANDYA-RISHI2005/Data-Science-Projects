# Student Performance Analyzer

A Data Analysis project that analyzes student academic performance and identifies factors that may influence final scores.

## Project Overview

The Student Performance Analyzer uses Python to analyze student-related data such as:

* Study Hours
* Attendance
* Assignment Score
* Mathematics Score
* Science Score
* English Score
* Final Score

The project performs data analysis and visualization to identify patterns and relationships between different factors and student performance.

## Objectives

The main objectives of this project are:

* Analyze overall student performance.
* Calculate subject-wise average scores.
* Identify top-performing students.
* Analyze the relationship between study hours and final scores.
* Analyze the relationship between attendance and final scores.
* Categorize students based on their performance.
* Identify students who need improvement.
* Generate visual insights using charts and graphs.

## Dataset

The dataset contains student academic information with the following features:

| Column           | Description                                   |
| ---------------- | --------------------------------------------- |
| Student_ID       | Unique identification number for each student |
| Gender           | Gender of the student                         |
| Study_Hours      | Number of hours spent studying                |
| Attendance       | Student attendance percentage                 |
| Assignment_Score | Score obtained in assignments                 |
| Math_Score       | Mathematics score                             |
| Science_Score    | Science score                                 |
| English_Score    | English score                                 |
| Final_Score      | Overall final score                           |
| Performance      | Performance category                          |
